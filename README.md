---

# Project Overview
This project is a JavaFX-based calendar and productivity application designed to help users manage tasks, events, reminders, and schedules through an interactive graphical user interface.

The application allows users to:
- Create and manage tasks
- Schedule and update events
- View daily, weekly, and monthly calendars
- Receive reminders and notifications
- Organize productivity tools in one system

The project follows object-oriented programming principles and separates the application into models, controllers, managers, and UI views.

---

# Features

## User & Authentication
- User login/logout
- Account information management
- Create/delete tasks
- Create/delete events

## Task Management
- Create tasks
- Set deadlines and priorities
- Mark tasks as complete
- Set and remove reminders

## Event Management
- Schedule events
- Update event information
- Cancel events
- Store event location, date, and time
- Event UI forms

## Calendar & Notifications
- Daily/weekly/monthly calendar views
- Calendar refresh system
- Notification scheduling
- Reminder triggering
